# Vento POS 🚀

Sistema de Punto de Venta (POS) y Facturación Electrónica moderno, robusto y diseñado para optimizar el flujo de operaciones comerciales y el cumplimiento fiscal.

## 📋 Características Principales

* **Facturación Electrónica (DTE):** Integración directa con el API del Ministerio de Hacienda (MH) de El Salvador para la emisión de Documentos Tributarios Electrónicos (códigos de generación, números de control y sellos de recepción).
* **Gestión Flexible de Pagos:** Soporte para múltiples métodos de pago, incluyendo efectivo, tarjetas (con registro de detalles de voucher), gestión de devoluciones y pagos mixtos (hasta 3 formas de pago combinadas en una sola transacción).
* **Importación Masiva de Productos:** Carga rápida y eficiente de inventario mediante plantillas de texto plano (TXT).
* **Interfaz Personalizable:** Opciones de configuración de temas visuales, tamaños de fuente y componentes de diseño adaptados al operador.
* **Arquitectura Confiable:** Desarrollado bajo un backend escalable y seguro.

## 🛠️ Tecnologías Utilizadas

* **Backend:** Java 21, Spring Boot
* **Base de Datos / Persistencia:** SQL Server / JPA / Hibernate
* **Integraciones:** API REST del Ministerio de Hacienda (El Salvador - DTE)
* **Control de Versiones:** Git & GitHub
